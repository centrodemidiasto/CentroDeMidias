# **App Name**: Agenda CME

## Core Features:

- Início: Apresentar o projeto e exibir imagens do Centro de Mídias Educacionais do Tocantins.
- Sobre: Detalhar a história e as atividades desenvolvidas no Centro de Mídias.
- Agendamento: Apresentar diretrizes e permitir a seleção de horários de agendamento semanais, das 09h00 às 18h00.
- Contato: Exibir as informações de contato do centro, incluindo e-mail, horário de funcionamento e endereço.
- Seleção Múltipla de Horários: Possibilitar a seleção de múltiplos horários dentro do mesmo dia para agendamento.
- Validação de Agendamento: Use an AI tool to check scheduling requests against business rules such as a schedule cannot be approved if the selected dates exceed one week, in addition to basic validation like dates within business hours and other constraints defined during set up.

## Style Guidelines:

- Primary color: Utilize um tom de azul vibrante (#2E9AFE) para transmitir profissionalismo e confiança, refletindo a seriedade do Centro de Mídias Educacionais.
- Background color: Use um azul bem claro e suave (#EBF5FB), quase neutro, para não competir com outros elementos.
- Accent color: Adote um laranja vivo (#FF851B) para destacar botões de ação e informações importantes, incentivando a interação.
- Body and headline font: 'PT Sans' (sans-serif) para garantir uma leitura confortável e acessível em todos os dispositivos.
- Code font: 'Source Code Pro' (monospace) para exibir qualquer código ou informação técnica de forma clara.
- Empregar ícones simples e intuitivos que representem as diferentes seções do site, facilitando a navegação e a compreensão das funcionalidades.
- Adicionar animações sutis para indicar o carregamento de informações ou a transição entre páginas, proporcionando uma experiência de usuário agradável e responsiva.
